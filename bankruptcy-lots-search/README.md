# Сервис поиска лотов по банкротству

Простой и понятный сервис для новичков, который помогает искать лоты на торгах по банкротству.

## 🚀 Возможности

- **Поиск по названию** - ищите лоты по ключевым словам в названии или описании
- **Фильтр по региону** - выберите нужный регион России
- **Фильтр по категории** - недвижимость, транспорт, оборудование и др.
- **Ценовой диапазон** - укажите минимальную и максимальную цену
- **Адаптивный дизайн** - работает на компьютерах и мобильных устройствах

## 📁 Структура проекта

```
bankruptcy-lots-search/
└── index.html          # Основной файл приложения (HTML + CSS + JS)
```

## 🔧 Как запустить

### Вариант 1: Просто открыть в браузере
1. Найдите файл `index.html` в папке проекта
2. Дважды кликните по файлу
3. Приложение откроется в вашем браузере

### Вариант 2: Использовать локальный сервер
```bash
# Если установлен Python 3
cd bankruptcy-lots-search
python3 -m http.server 8000

# Откройте в браузере: http://localhost:8000
```

## 💡 Как пользоваться

1. **Введите параметры поиска:**
   - Название или описание (например: "квартира", "автомобиль")
   - Выберите регион из списка
   - Выберите категорию лота
   - Укажите ценовой диапазон (необязательно)

2. **Нажмите кнопку "Найти лоты"**

3. **Изучите результаты:**
   - Каждый лот показывает цену, регион, категорию
   - Подробное описание лота
   - Информация о должнике и дате торгов

4. **Сохраните понравившиеся лоты** кнопкой "Сохранить"
