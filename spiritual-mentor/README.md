# Сервис поиска духовного наставника

Веб-приложение для поиска христианских священников и пасторов различных конфессий.

## Функционал

### Для пользователей:
- Поиск священников по имени, городу или деноминации
- Фильтрация по конфессиям (Православие, Католицизм, Протестантизм)
- Просмотр карточек священников с информацией:
  - Фото (символическое)
  - Имя и контакты
  - Конфессия и деноминация
  - Местоположение
  - Биография
  - Рейтинг и опыт
- Возможность написать сообщение священнику
- Добавление в избранное
- Чтение публикаций от священников
- Оставление комментариев к публикациям
- Регистрация и вход

### Для священников:
- Регистрация как священник с указанием:
  - Конфессии
  - Деноминации
  - Местоположения
  - Биографии
- Создание публикаций для верующих
- Получение сообщений от пользователей

## Технологии

- **React 18** - UI библиотека
- **TypeScript** - типизация
- **React Router** - навигация
- **Vite** - сборщик
- **CSS3** - стилизация с современным дизайном

## Запуск проекта

```bash
cd spiritual-mentor
npm install
npm run dev
```
